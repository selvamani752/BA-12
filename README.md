# Geographical Sales Analysis Using Tableau Public

## 1. Introduction
Geographical Sales Analysis is the process of studying sales and profit performance across different regions. This project uses Tableau Public to visualize and analyze sales data through interactive charts and dashboards.

## 2. Objective
The main objective of this project is to analyze sales performance across different regions and product categories, identify business trends, and understand regional variations in sales and profit.

## 3. Tools Used
- Tableau Public
- Sales Dataset (CSV)
- Data Visualization and Exploratory Data Analysis

## 4. Visualizations Created
1. **Sales by Region:** Compares total sales across different regions.
2. **Sales by Category:** Shows sales performance across product categories.
3. **Profit by Region:** Compares profit generated by each region.
4. **Quantity by Category:** Displays the quantity of products sold in each category.

## 5. Interactive Filters
- **Region Filter:** Allows users to view data for selected regions.
- **Category Filter:** Allows users to explore sales data for selected product categories.

## 6. Dashboard
A single interactive dashboard combines all four visualizations. Users can apply filters to explore sales, profit, and quantity information from different perspectives.

## 7. Key Findings
1. The region with the highest sales can be identified through the regional sales chart.
2. The best-performing product category can be identified by comparing category-wise sales.
3. Regional profit differences help identify areas of strong and weak business performance.

## 8. Recommendations
1. Focus on improving marketing and product availability in regions with lower sales.
2. Maintain sufficient inventory and strengthen promotional activities for high-performing product categories.
